S.R.TRACK — VERSION CAMION RÉEL + ANIMATIONS

CONTENU À PUBLIER ENSEMBLE
- index.html
- script.mjs
- assets/ (toutes les images)

IMPORTANT
Ne publie pas index.html seul. Le site utilise les fichiers du dossier assets/ et script.mjs.
Sur GitHub Pages, conserve exactement la structure des dossiers.

ANIMATIONS
1. Camion réel en circulation avec parallaxe et route animée.
2. Vue éclatée pilotée par le scroll : cabine, remorque et châssis se séparent.
3. Cutaway de cabine avec photo réelle de l'intérieur.
4. Quatre balises GPS pulsent, se déplacent vers leurs points de pose et envoient des données.
5. Visuels photo complémentaires synchronisés avec le scroll.
6. Tableau de contrôle holographique, satellites et flux de données.

FALLBACK
Si WebGL/Three.js ou le CDN n'est pas accessible, une photo réelle du camion est affichée automatiquement au lieu d'une page vide.
